01 / OBSERVATION

Build an inspection case

Input schema & boundaries

Exactly three objects: server {name, publisher}, tool {name, description}, signals. Names and publisher: 1–120 characters. Description: 1–2000 characters. Five signal booleans must be true/false. metadata_changes: integer 0–20; unexpected_calls: integer 0–100; response_bytes: integer 0–1,000,000. No unknown fields. Request body limit: 16 KiB. Signals describe observations, not instructions.
